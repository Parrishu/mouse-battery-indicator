# Mouse Battery Indicator

**See your Logitech mouse battery level right in the Windows system tray.**

![Mouse Battery Indicator in the Windows taskbar](docs/icon-screenshot.png)

## Features

- Supports many Logitech HID++ mice connected by receiver or USB
- Shows battery level, charging status, and optional battery notifications
- Switches between a battery icon and percentage display
- Includes installer and portable versions

Battery information varies by mouse model and firmware. The app displays one detected battery-capable mouse at a time.

## Download

Get the latest installer or portable app from [Releases](https://github.com/Parrishu/mouse-battery-indicator/releases/latest).

For portable use, run `MouseBatteryIndicatorPortable.exe`. Settings and logs are stored beside the executable.

## Origin

This project began as a fork of [Headset Battery Indicator](https://github.com/aarol/headset-battery-indicator) by Aaro Luomanen. It has since been independently developed as a dedicated Logitech mouse battery app.
